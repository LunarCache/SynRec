# CMREC 可视化系统完整指南

## 📊 概述

CMREC系统集成了完整的可视化分析工具，用于深入理解模型的学习行为、专家专业化程度和领域自适应能力。本文档详细介绍所有可视化功能的含义、解读方法和效果识别标准。

## 🔧 可视化启用

```bash
# 启用完整可视化功能
python main.py --visualize True --tsne_log_freq 1 --log_freq 100 --use_wandb True
```

**核心参数说明:**
- `--visualize`: 启用/禁用可视化功能
- `--tsne_log_freq`: t-SNE分析频率（epoch间隔）
- `--log_freq`: 常规可视化记录频率（step间隔）
- `--use_wandb`: 启用WandB云端可视化

## 📈 1. 多领域Fourier评分注意力可视化

### 1.1 功能概述
分析领域自适应Fourier评分编码器的注意力模式，展示不同领域如何学习不同的时序偏好模式。

### 1.2 可视化内容
每个图表包含3个子图：
1. **短期注意力 (Short-term Attention)** - 红色色调
2. **长期注意力 (Long-term Attention)** - 蓝色色调  
3. **自适应权重 (Adaptive Weights)** - 绿色色调

### 1.3 查看位置
- **TensorBoard**: `Fourier_Rating_Detail_Domain{X}/Layer_{Y}_Detailed`
- **WandB**: `rating_attention_detailed/fourier_rating_detail_domain{X}_layer_{Y}_fourier_analysis`

### 1.4 解读方法

#### 短期注意力模式 (高频模式)
```
效果良好的特征:
✅ 对角线附近有明显的高亮区域 (关注近期评分)
✅ 局部热点集中 (短期偏好模式清晰)
✅ 不同领域呈现不同的局部模式

效果不佳的特征:
❌ 完全随机分布 (无明显模式)
❌ 过度集中在单点 (过拟合)
❌ 所有领域模式相同 (无领域专业化)
```

#### 长期注意力模式 (低频趋势)
```
效果良好的特征:
✅ 整体呈现渐变模式 (捕获长期趋势)
✅ 跨越更大时间窗口的注意力
✅ 领域间有明显差异

效果不佳的特征:
❌ 与短期注意力模式完全相同
❌ 无渐变特征 (未学习到长期模式)
❌ 注意力过于分散
```

#### 自适应权重分布
```
理想状态:
✅ 三种尺度(原始/短期/长期)权重有明显差异
✅ 权重分布随序列位置变化
✅ 不同领域呈现不同的权重策略

问题状态:
❌ 权重分布过于均匀 (未学习到自适应性)
❌ 单一尺度权重过大 (退化为单尺度模型)
❌ 权重不随位置变化 (静态权重)
```

### 1.5 领域差异分析
```
beauty_5_5领域: 短序列，应显示更多短期注意力
games领域: 中等序列，平衡的短期/长期注意力
ml-1m_rated领域: 长序列，更多长期注意力模式
```

## 🎯 2. 领域-专家路由热力图

### 2.1 功能概述
展示MoE系统中每个领域如何选择和使用不同的专家，反映专家专业化程度。

### 2.2 查看位置
- **TensorBoard**: `Domain_Expert_Routing/Heatmap`
- **WandB**: `domain_expert_routing/heatmap`
- **本地文件**: `Domain_Expert_Routing_Heatmap.png`

### 2.3 解读方法

#### 专家专业化良好
```
✅ 清晰的对角线模式 (领域-专家对应关系)
✅ 某些专家对特定领域有明显偏好 (数值 > 0.7)
✅ 不同领域的路由分布有明显差异
✅ 共享专家被多个领域适度使用 (0.3-0.6)
```

#### 专家专业化不佳
```
❌ 所有值接近均匀分布 (0.25左右，4专家情况)
❌ 单个专家被过度使用 (某列数值全部 > 0.8)
❌ 某些专家从未被使用 (某列数值全部 < 0.1)
❌ 领域间路由模式完全相同
```

### 2.4 具体数值解读
```
数值范围说明:
- 0.8-1.0: 专家高度专业化，主要服务该领域
- 0.5-0.8: 专家较多关注该领域
- 0.2-0.5: 适度使用，良好的负载均衡
- 0.0-0.2: 专家很少服务该领域
```

### 2.5 路由策略差异

#### shared_base策略
```
期望模式:
- 标签为"Expert 0-3"中性命名
- 观察自然涌现的专业化模式
- 无预设的共享/专用划分
```

#### vanilla策略  
```
期望模式:
- 显式标记"(Shared)"的共享专家
- 共享专家应被多领域使用
- 专用专家应显示明确的领域偏好
```

## 🔬 3. t-SNE专家专业化分析

### 3.1 功能概述
通过降维可视化分析专家嵌入的聚类情况，验证专家是否学习到不同的表示模式。

### 3.2 查看位置
- **TensorBoard**: `t-SNE_Specialization`
- **WandB**: `tsne_specialization`
- **本地文件**: `t-SNE_Specialization.png`

### 3.3 可视化内容
双子图展示：
1. **左图**: 按专家ID着色的嵌入分布
2. **右图**: 按领域ID着色的嵌入分布

### 3.4 解读方法

#### 专家专业化良好
```
左图(按专家着色):
✅ 不同颜色的点形成明显的聚类
✅ 相同专家的点聚集在一起
✅ 不同专家的聚类有明确边界
✅ 聚类数量与专家数量匹配

右图(按领域着色):
✅ 不同领域在空间中有一定分离
✅ 同一领域内部有结构化分布
✅ 跨领域重叠区域显示共享知识
```

#### 专业化不足
```
左图问题:
❌ 所有专家的点完全混合，无聚类
❌ 某些专家无对应的点 (未被使用)
❌ 聚类过于集中 (专家差异性不足)

右图问题:
❌ 不同领域完全重叠 (无领域特征)
❌ 领域分布过于分离 (缺少知识共享)
❌ 单一领域占据整个空间 (其他领域被忽略)
```

### 3.5 采样和质量控制
```
技术参数:
- 采样规模: 512个点 (--tsne_sample_size)
- 困惑度: 30 (适合中等规模数据)
- 学习率: 200 (平衡收敛速度和质量)
- 最大迭代: 1000次
```

## 📊 4. TensorBoard系统监控

### 4.1 核心监控指标

#### 损失曲线
```
路径: Scalars/Loss
- bpr_loss: BPR推荐损失 (应持续下降)
- load_balancing: 负载均衡损失 (应维持在较低水平)
- specialization: 专业化损失 (促进专家差异化)
- contrastive: 对比学习损失 (增强表示质量)
```

#### 专家负载分布
```
路径: Scalars/Expert_Load_Distribution
监控内容:
- 各专家的使用频率是否均衡
- 是否存在专家"闲置"或"过载"
- 负载分布随训练的变化趋势
```

#### 评估指标
```
路径: Scalars/Evaluation (每epoch记录)
核心指标:
- NDCG@10/20: 归一化累计折扣增益
- HR@10/20: 命中率
- MRR: 平均倒数排名
- 按领域分别统计的性能指标
```

### 4.2 理想状态指标
```
✅ BPR损失: 训练初期快速下降，后期缓慢收敛
✅ 负载均衡: 维持在0.001-0.01之间
✅ 专业化损失: 逐渐下降至稳定值
✅ NDCG@10: 持续提升，收敛在合理范围
✅ 专家负载: 各专家使用率在0.2-0.3之间
```

## ⚠️ 6. 常见问题和解决方案

### 6.1 可视化生成失败
```
问题: 图表生成异常或缺失
解决方案:
1. 检查matplotlib后端设置
2. 确认--visualize参数为True
3. 验证WandB连接状态
4. 查看内存使用情况
```

### 6.2 多领域可视化错误
```
问题: 领域标识混乱或图表重叠
解决方案:
1. 确认domain_ids正确传递
2. 检查数据预处理中的领域映射
3. 验证可视化函数的命名策略
```

### 6.3 专家专业化不明显
```
问题: t-SNE聚类不清晰，路由热力图过于均匀
优化方案:
1. 调高专业化损失权重 (--specialization_weight)
2. 降低门控温度 (--gate_temperature)
3. 增加训练轮数
4. 检查MoE配置参数
```

### 6.4 性能瓶颈
```
问题: 可视化拖慢训练速度
优化方案:
1. 降低可视化频率 (--log_freq, --tsne_log_freq)
2. 减少t-SNE采样数量 (--tsne_sample_size)
3. 关闭部分可视化功能
4. 使用异步可视化记录
```

## 🎯 7. 效果评估标准

### 7.1 优秀效果特征
```
Fourier注意力:
✅ 领域间差异明显，模式清晰
✅ 短期/长期注意力有明确分工
✅ 自适应权重动态变化

专家路由:
✅ 专业化指数 > 0.6
✅ 负载均衡系数在0.8-1.2之间
✅ 领域覆盖率 > 90%

t-SNE分析:
✅ 轮廓系数 > 0.3
✅ 聚类清晰度高
✅ 专家-领域对应关系明确
```

### 7.2 需要优化的情况
```
注意力模式:
❌ 随机分布，无明显结构
❌ 所有领域模式雷同
❌ 权重分布过于静态

路由模式:
❌ 专业化指数 < 0.3
❌ 存在闲置专家 (使用率 < 0.1)
❌ 单专家过载 (使用率 > 0.8)

聚类效果:
❌ 轮廓系数 < 0.1
❌ 专家嵌入完全混合
❌ 领域特征不可区分
```

## 📚 8. 实验分析流程

### 8.1 训练期间监控
1. **实时检查**: TensorBoard损失曲线和指标趋势
2. **周期分析**: 每5-10个epoch检查可视化更新
3. **异常检测**: 监控是否出现损失爆炸或收敛停滞

### 8.2 训练完成后分析
1. **整体评估**: WandB实验对比和指标汇总
2. **细节分析**: 下载关键可视化图表进行深入研究
3. **模式验证**: 确认专家专业化和领域自适应效果

### 8.3 实验报告生成
1. **数据收集**: 汇总所有可视化结果和定量指标
2. **趋势分析**: 分析训练过程中的模式演化
3. **效果验证**: 对比不同配置和超参数的影响
4. **结论总结**: 基于可视化证据得出实验结论
